# Detectivelens-AI-Deriven-forgered-image-and-website-detection-using-GRADCAM
Detective Lens is an AI-powered mobile application that detects forged and AI-generated images, identifies manipulated regions, and traces the source of image modifications. It uses advanced deep learning models such as EfficientNet-B4, YOLOv8, Vision Transformer (ViT), and Error Level Analysis (ELA) to provide accurate forgery detection and localization. Grad-CAM and Segment Anything Model (SAM) generate visual heatmaps and masks, making the detection process explainable. The application also performs source tracing using perceptual hashing, platform fingerprinting, and the Hive AI API to identify whether an image originated from social media platforms or AI image generation tools.
